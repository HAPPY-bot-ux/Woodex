🌲 Woodex Website README
Welcome to the Woodex project! This website is designed to showcase all things related to wood products, from furniture to timber solutions. Built using HTML, CSS, and JavaScript, Woodex offers a user-friendly and visually appealing platform for those interested in wood-related products and services. Whether you're a homeowner, builder, or enthusiast, this site will provide all the information you need about quality wood products and their applications.

🧐 Project Overview
Woodex is a modern and interactive website created to highlight various wood products, including their uses, benefits, and types. With a clean, intuitive design and interactive features, users can explore a range of content about the wood industry, from timber and wood types to woodworking techniques and more.

The website utilizes:

HTML for structuring the content and creating web pages.
CSS for styling and ensuring an aesthetically pleasing layout.
JavaScript to implement dynamic elements and interactivity.
💻 Technologies Used
HTML:

Utilized to create the fundamental structure of the website, including content like headings, images, sections, and links.
CSS:

Used to style the layout, fonts, and colors of the website, as well as for responsive design to ensure the site is usable on any device.
JavaScript:

Powers interactive elements, such as navigation menus, dynamic content loading, and user-triggered actions like form submissions and image sliders.
✨ Features
🏠 Home Page:

A welcoming introduction to Woodex, showcasing the core values of the company, as well as featured products and services.
🪑 Product Catalog:

Displays a wide range of wood-based products (such as furniture and decor), with detailed descriptions and images.
🌳 Wood Types & Benefits:

A section dedicated to educating users about different types of wood and their unique benefits, helping users make informed decisions.
📱 Responsive Design:

The website is fully responsive and works seamlessly across all devices (mobile, tablet, desktop), ensuring an optimal user experience.
🎨 Interactive Image Gallery:

A gallery featuring wood products with hover effects, modals for detailed views, and smooth transitions.
🖱️ JavaScript Interactivity:

Includes dynamic elements like a scroll-to-top button, collapsible sections for FAQs, and navigation enhancements.
